
# 📚 Online Book Reservation System

## About the Project
The Online Book Reservation System is a web application designed to manage books and reservations. Users can view available books, while administrators can manage book details and reservations.

## Technologies Used

### Frontend
- React.js
- JavaScript
- CSS
- Vite

### Backend
- Node.js
- Express.js
- MySQL

## Features
- View available books
- Manage book details
- Add and delete books
- Manage reservations
- Admin dashboard

## Project Structure
- backend – Server-side application
- frontend – React user interface

## Installation

Clone the repository:

```bash
git clone https://github.com/talamarlasandhya/Online-Book-Reservation.git
```

Install backend dependencies:

```bash
cd backend
npm install
```

Install frontend dependencies:

```bash
cd ../frontend
npm install
```

## Running the Project

Start the backend and frontend separately using the scripts configured in their respective package.json files.
