# Online Book Reservation System

## 📚 Project Overview

The **Online Book Reservation System** is a web-based application that allows users to browse available books, search for books, and reserve their favourite books online.

The application also provides an Admin Dashboard to manage book inventory and monitor reservations.

## ✨ Features

### User Features
- View available books.
- Search books by title or author.
- Reserve available books.
- View personal reservations.
- Check book availability.

### Admin Features
- Admin Dashboard.
- View total books and reservations.
- Add new books.
- Edit and delete book details.
- Manage book inventory and available stock.

## 🛠️ Technologies Used

- **Frontend:** HTML, CSS, JavaScript, React / Vite
- **Backend:** Node.js, Express.js
- **Database:** MySQL
- **Version Control:** Git and GitHub

## ⚙️ Installation and Setup

### 1. Clone the Repository

```bash
git clone https://github.com/talamarlasandhya/Online-Book-Reservation.git
```

### 2. Open the Project

```bash
cd Online-Book-Reservation
```

### 3. Setup Backend

```bash
cd backend
npm install
npm start
```

Backend runs at:

`http://localhost:5000`

### 4. Setup Frontend

Open another terminal:

```bash
cd frontend
npm install
npm run dev
```

Open the frontend URL displayed in the terminal.

## 🗄️ Database

This project uses MySQL for database management.

Make sure MySQL is installed and running. Configure your database connection using the settings required by the backend.

Do not upload database passwords or secret credentials to GitHub.
